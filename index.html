Bantuan koneksi
  1. Di MakeCode: tambah ekstensi Bluetooth dan blok "bluetooth uart service" di awal program.
  2. Paling mudah: di Project Settings nyalakan "No Pairing Required", lalu flash ulang.
  3. Kalau memakai pairing: tekan A+B lalu reset, dan masukkan kode 6 digit yang tampil di LED.
  4. Pernah dipairing dan gagal? Hapus "BBC micro:bit" di pengaturan Bluetooth perangkat, lalu reset micro:bit.
  5. Micro:bit hanya menerima satu koneksi. Tutup MakeCode pairing atau aplikasi micro:bit lain.
  6. Tidak muncul di daftar? Centang "Tampilkan semua perangkat".

build now!

Tips pemula

Pilih jenis widget, isi nama dan kunci data (huruf kecil tanpa spasi, misalnya “light”), lalu tekan Tambah widget. Kunci data adalah nama panggilan yang dikirim ke micro:bit.

Catatan teknis

Kunci dinormalisasi ke huruf kecil dan karakter [a-z0-9_]. Switch mengirim key:1 atau key:0, Tombol mengirim key:1, Slider mengirim key:<nilai> dalam rentang min–max (laju kirim dibatasi), Sensor menampilkan nilai dari baris masuk key:value.

CONTROLLER

drive now!

Tips pemula

Hubungkan micro:bit dulu. Tahan tanda panah untuk bergerak dan lepaskan untuk berhenti. Tombol panah di keyboard juga bisa dipakai. Untuk mengangkut barang: dekati barangnya, tekan CAPIT, bawa ke tujuan, lalu tekan LEPAS.

Catatan teknis

Perintah dikirim sebagai teks + newline sesuai mapping di Settings (default up, down, left, right, stop). Perintah stop dikirim saat semua tombol dilepas. CAPIT dan LEPAS (default grip, release) dikirim satu kali per tekan dan tidak memengaruhi gerakan. Input: pointer/touch, panah keyboard, C dan L.

Hubungkan micro:bit lewat tombol di sidebar untuk mulai mengontrol.

detect now!

Tips pemula

AI Vision (hand gesture): latih model gestur tangan di Teachable Machine, salin shareable link-nya ke sini, lalu tekan Start kamera. Deteksi mobil ada di menu Smart Parking.

Catatan teknis

Model Teachable Machine (TensorFlow.js, inferensi di browser); hanya satu kamera aktif pada satu waktu (juga terhadap kamera Smart Parking). Nama class dikirim sebagai perintah jika confidence ≥ threshold (0,50–0,99), saat berubah dan diulang berkala selama class yang sama bertahan.

Latih class gestur tangan: up, down, left, right, stop (atau grip/kepal dan release/telapak). Di Teachable Machine: Export Model, tab Tensorflow.js, Upload my model, lalu salin shareable link-nya.

Perintah hanya dikirim jika confidence sama atau di atas threshold.

SMART PARKING

park smart!

Tips pemula

Klik maskot micro:bit di judul: mobil datang dulu, lalu maskotnya lompat naik dan kabur. Hubungkan micro:bit, lalu lihat slot parkir berubah merah saat ada mobil. Kamera Teachable Machine bisa mendeteksi mobil otomatis (class dikirim sesuai namanya), dan tombol Buka/Tutup Palang tetap tersedia. Sensor micro:bit mengirim masuk1 sampai masuk3 dan keluar1 sampai keluar3.

Catatan teknis

Memakai koneksi BLE Nordic UART yang sama dengan menu Controller (service 6e400001-b5a3-f393-e0a9-e50e24dcca9e). Masuk: masuk1–3 / keluar1–3 (newline). Keluar: "mobil" (buka palang) dan "kosong" (tutup palang). Kamera Teachable Machine (threshold default 0,85) mengirim nama class apa adanya dan memperbarui slot yang dipilih.

SETTINGS

map now!

Tips pemula

Di sini kamu memilih kata yang dikirim ke micro:bit saat tombol D-Pad, CAPIT, dan LEPAS ditekan. Ubah kalau program micro:bit-mu memakai kata yang berbeda.

Catatan teknis

Mapping disimpan di localStorage browser (jokowi.map) dan dipakai Controller. Maksimal 30 karakter per perintah; program micro:bit harus mem-parse string yang sama persis.

Atur teks yang dikirim ke micro:bit saat D-Pad ditekan atau dilepas, dan saat tombol capit atau lepas capit ditekan.
